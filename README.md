# INSANMOY CONNECT — MikroTik HotSpot

Empat template login HotSpot yang responsif untuk desktop dan ponsel.

- `template1` — Karimunjawa, nuansa laut.
- `template2` — Pantai pastel.
- `template3` — Awan dan pelangi yang cute.
- `template4` — Gaya baddie, hitam dan hot pink.

Buka `index.html` untuk pratinjau. Untuk MikroTik, gunakan `login.html` dan sertakan file pendukung dalam folder template. Pertahankan `md5.js` jika HotSpot memakai HTTP-CHAP.
